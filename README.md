# StoryEasy

输入一句话创意，AI 生成一个可玩的文字互动故事：世界设定、角色属性、分支剧情与写实场景插图全部由模型实时生成，每个选择都会改变结局。

Next.js 全栈，服务端无状态，可部署在 Vercel 免费版（无需数据库）。

## 演示流程

1. 输入一句话创意（例："魔教余孽潜入正派扫地，悟出绝学后揭穿正邪之分不过是掩盖血案的谎言"）
2. 等待约 20-40 秒构建世界，期间显示真实进度百分比
3. 进入游戏，图文同时呈现
4. 点击选项推进剧情，最多 15 回合，属性归零或剧情收束时进入结局

## 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Next.js 16（App Router） |
| 语言 | TypeScript（strict） |
| 样式 | Tailwind CSS v4 |
| 校验 | Zod |
| 模型调用 | OpenAI SDK（兼容任意 OpenAI 协议服务） |
| 文生图 | Pollinations（免费，无需 key） |

依赖仅 5 个运行时包，约 2000 行源码。

### 服务端无状态

游戏进度（属性、物品、历史）全部由客户端持有，每次请求随 body 回传并经 Zod 校验。

这是能在 Vercel 免费版部署的前提——不需要数据库、不需要 session、函数实例可随意销毁重建。代价是请求体随剧情增长，因此历史记录做了摘要压缩（见下）。

### 流式协议：正文流式 + 元数据尾随

回合推进需要同时拿到「叙事正文」和「结构化元数据」（选项、属性变化、是否结局）。若等模型输出完整 JSON 再返回，首字延迟会达到 8 秒以上。

做法是让模型先输出正文，再用分隔符 `<<<META>>>` 跟一段 JSON：

```
你拧死内舱门的三道插销……（正文，边生成边推送）
<<<META>>>
{"choices":[...],"statChanges":{"体力":-5},"newItems":["羊毛手套"],"isEnding":false}
```

服务端按分隔符切分，正文走 SSE `text` 事件增量推送，JSON 解析后走一条 `meta` 事件。**首字延迟约 7.5 秒，完整回合约 8-9 秒。**

实现上有两个必须处理的细节：
- 分隔符可能被切在两个 chunk 之间，因此推送时尾部保留分隔符长度的缓冲（[turn/route.ts](src/app/api/story/turn/route.ts)）
- 元数据解析失败时返回兜底选项而非报错，保证游戏能继续

### 预取分支树：零等待交互

玩家阅读当前剧情时，后台**并发**为每个选项各生成一个完整回合并缓存。点击时：

| 分支状态 | 行为 |
|---|---|
| `ready` | 立即呈现，**0ms** |
| `pending` | 复用在途请求并显示进度，不重新发起 |
| `failed` / 未命中 | 回退到实时流式生成 |

选定后取消其余分支，并立刻为新回合启动下一轮预取——树滚动延伸，玩家全程零等待。

**实测：3 个分支并发 7.3 秒完成（串行需约 26 秒），点击取用 0ms。**

剧情走向仍由玩家选择真实决定，不是预制线性剧本。代价是 3 倍 token 消耗，可通过 [prefetch.ts](src/lib/story/prefetch.ts) 的 `PREFETCH_MODE` 降级为 `first`（只预取首选项）或 `off`。

几个容易出错的地方：
- **分支 key 必须带回合数前缀**。不同回合可能出现文本完全相同的选项（元数据解析失败时的兜底选项就是固定的三条），只用文本会把旧回合的分支错当成当前回合，剧情接不上且不报错
- **每个分支独立 AbortController**。提交时要「保留选中分支、取消其余」，共用一个会把刚选中的（插图可能还在途）一起取消
- **预取缓存只放 ref**。三个分支并发流式每秒产生数十次回调，进 state 会打满主线程；且存档 effect 会把它一起写进 localStorage 撑爆配额
- **被丢弃的分支 promise 需挂空 catch**，否则产生 unhandled rejection

### 插图：异步降级 + 预热

插图是**非关键路径**：基于完整叙事生成，任何失败（限流、超时、非法响应）都静默降级为纯文字，绝不阻塞剧情。

中文剧情先经模型翻译成英文摄影 prompt 再送去画图——实测中文 prompt 的写实度与贴合度都明显更差。

```
叙事（中文） → 模型翻译为英文摄影 prompt（约 8s） → 文生图（约 35s） → 预热落缓存 → <img> 秒开
```

**图片请求必须串行。** 实测 Pollinations 免费层有全平台共享的上游限流（`Per-user limit of 300 RPM exceeded`）：并发 4 路只有 1 路成功、其余 429/500；串行则 100% 成功。因此所有图片请求走同一队列、间隔 800ms 发出，并带退避重试（[image-warm.ts](src/lib/story/image-warm.ts)）。

同一 URL 首次请求触发生成并落入服务端缓存，再次请求约 1 秒。所以开局刻意等到开场插图**预热完成**才进入游戏，玩家进入时图文同时秒开；进入后在后台串行预热分支插图。

**实测：开局 16-25 秒，玩家加载已预热图片 979ms / 1280ms（未预热需约 45 秒）。**

同样因为上游限流，放弃了「开局预热全部 4 张图」的方案——串行需约 170 秒，超出可接受的等待。分支插图因此可能仍需等待，届时显示进度条。

### 进度反馈

文生图是一次 GET 返回整图，过程中无任何进度回传，且耗时的绝大部分在服务端排队与生成（字节要到最后一两秒才下来）。按下载字节算"真实"进度会呈现「0% 卡 40 秒后瞬间 100%」，比估算更像卡死。

因此采用时间驱动的爬升（[useCreepingProgress.ts](src/lib/useCreepingProgress.ts)）：按实测耗时换算速度，封顶 95% 后文案改为「仍在绘制，请稍候」，不虚报即将完成。已预热的图约 1 秒即到，跳过进度条只用微光占位避免闪烁。

### 状态机与 LLM 的协调

纯 LLM 叙事会失控（属性、物品无人管理），纯状态机又失去自由度。做法是划分职责：

- **LLM 负责**：叙事、选项设计、判定行动后果（输出属性增量与新物品）
- **代码负责**：属性上下界钳制、物品去重、结局判定、回合数控制

属性归零一律触发坏结局（与 prompt 中的规则一致，代码侧兜底）；达到最大回合数时若模型仍未收束，服务端强制置为结局，避免玩家卡在无选项状态。

### 上下文成本控制

对话历史会随回合线性增长。近 6 回合完整保留，更早的压缩为一行摘要：

```
第1回合：玩家「照女人吩咐弹琴」→ 你掀开琴盖落座，指尖还带着凉意…
```

见 [prompts.ts](src/lib/story/prompts.ts) 的 `buildHistoryMessages`。

### 安全与成本防护

- **API key 只在服务端**。所有模型调用走 Route Handler 代理，前端永不接触 key
- **限流按接口分桶**（[rate-limit.ts](src/lib/rate-limit.ts)）：`turn`/`illustrate` 各 60/分钟（预取使请求量放大 3 倍），`setup` 5/分钟（每局一次且最贵，收紧防刷开局）
- **透传取消信号**。`req.signal` 传入上游模型调用，取消的预取分支立即停止生成，不再消耗 token
- **所有边界数据经 Zod 校验**，模型输出、请求体一律不信任

限流为进程内内存实现。Vercel Serverless 多实例不共享内存，因此是「尽力而为」的防护——能拦住脚本刷量，跨实例可能略超。生产级方案应换 Upstash Redis，但这与「免费版无数据库」的约束冲突，当前场景接受不精确。

## 本地运行

```bash
pnpm install
cp .env.example .env.local   # 填入 AI_API_KEY 与 AI_MODEL
pnpm dev
```

环境变量：

| 变量 | 必填 | 说明 |
|---|---|---|
| `AI_API_KEY` | 是 | 任意 OpenAI 兼容服务的 key |
| `AI_MODEL` | 是 | 模型名，如 `gpt-4o-mini` / `deepseek-chat` |
| `AI_BASE_URL` | 否 | 留空走 OpenAI 官方；用中转网关时填写（注意是否需要 `/v1` 后缀） |
| `IMAGE_BASE_URL` | 否 | 文生图地址，默认 Pollinations |
| `IMAGE_MODEL` | 否 | 文生图模型，默认 `flux` |

## 部署

推送到 GitHub 后在 Vercel 导入，配置上述环境变量即可。无需数据库。

注意：公开部署意味着任何人都能消耗你的 API 额度。已内置 IP 限流，但如需长期开放建议追加访问口令或总量熔断。

## 已知限制

- **分支插图可能需要等待**。文字是稳定秒开的（预取已就绪），但一张新图需 13-45 秒，能否在玩家阅读期间生成完取决于当时上游拥堵程度。要做到全程图文秒开需换付费画图渠道（无共享限流，可并发）
- **图片带第三方水印**。Pollinations 免费层强制添加，`nologo` 参数无效
- **自由输入会使预取失效**。玩家用输入框自定义行动时，预取的分支全部作废，退回实时生成
- **限流跨实例不精确**，见上文
